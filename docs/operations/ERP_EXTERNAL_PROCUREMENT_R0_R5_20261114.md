# ERP 外采履约 V1（Owner 2026-11-14）

## R0–R5 rule
- 分仓允许 OUTSOURCE 作为虚拟采购来源。仅中国工厂 FACTORY 是实际发给客户的仓库；OUTSOURCE 不登记实物库存，不绕过仓库 SKU 门禁。
- Vita 分仓确认每个 SKU 的采购来源。整单采购或 A/B/C 子订单部分采购均按实际履约 Order ID 生成独立采购单，原单及人工修改的 SKU、地址不被 Woo 自动同步覆盖。
- 国内发货第 3 个 View：「外采单」专属于真实外采、客户未发货订单；采购放行后仍在此 View 跟进，直到客户订单已发货才退出。中国工厂待审核、缺货与待发货 View 严格排除未放行外采。
- Zhang 具备采购权限但无需 logistics.view，只能操作采购 View：待采购 → 采购中 → 已下单 → 已到货（真实 SKU、逐项到货数量、工厂收货凭据）。采购单号/采购物流单号不能写入客户发货单。
- Vita 必须同时拥有 orders.edit、domestic.review 才能在完整到货后以原有国内审核服务放行到待发货；Kaven 不能在到货前通过普通国内审核绕过采购门禁。
- Liang 只从待发货队列交由原有物流服务处理（速达、纬狮），不得提前导出未到货订单。
- 已采购或已到货订单禁止 Vita 静默重新分仓，尚未开始的外采任务在新分仓取消时注销，防止孤儿采购单。
- 采购状态完成仅在客户实发后触发；已到货和释放属于采购子状态，不影响 Woo 原订单状态，源订单始终可追溯。
- 所有关键状态变更记审计日志，采购通知发给采购权限成员、到货通知发给国内审核权限成员。
- 原先缺货采购工作流继续可用，不要求对历史采购单升级新状态。

## Acceptance & release safety
1. Vita 单仓/混合分仓成功，新增 external PO 关联到正确实际物流单，库存未知不会生成已到货假记录。
2. Zhang 仅可读取国内外采 View、更新采购物流与实际收到的每项 SKU/数量；无效数据/非源商品禁止放行。
3. Vita 放行后订单从待审核门禁直接进入国内待发货；采购 View 保留到实际客户发货。
4. 已有 Kaven 正常国内审核/物流商导出/ShipOut MorePlus/30 Tab/人工 ERP 编辑保护回归通过。
5. PR 单独 CI 全绿、Production 全库备份、受控迁移与软链接原子发布、007windows 健康验收；保留回滚旧版本。
