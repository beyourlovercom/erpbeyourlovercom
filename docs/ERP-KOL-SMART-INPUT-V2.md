# ERP 网红智能录入 V2 — 已确认交互方案

## 已确认的产品决策
- Username 优先，创建网红与创建网红履约订单两个业务入口共用本地快捷录入。
- 输入单个 Username 或粘贴合作资料，一次点击「识别并检索」，本地解析并填入可识别字段。
- 只有一个精确账号匹配时，订单入口自动选择已有档案；模糊或多个匹配必须人工选择。
- 已有网红优先读取原档案收件地址；只有粘贴了地址字段时才出现可选的采用粘贴地址按钮。
- 新网红先建档，自动批准并复用既有 AffiliateWP/Coupon 开户服务；可以只建档不下订单。
- 从订单入口开始时保留加密草稿，成功开户后回到订单。产品提示不是 SKU 选择；员工核对实际 SKU 与本次收件信息。
- 未识别字段不阻止录入；保留原文提示，员工直接在表单中补充。
- 不显示 AI 调用按钮，不等待 Codex，不依赖 Mac mini。AI Worker 实验接口、独立代码及服务保留，默认关闭，不是本功能的发布阻塞项。
- 沿用既有员工权限、重复开户保护和真实物流字段规则，不新增地址识别审核。
