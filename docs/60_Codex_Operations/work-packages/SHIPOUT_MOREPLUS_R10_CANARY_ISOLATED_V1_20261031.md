Existing attempt of ANY status blocks ALL future automatic retries (including after ambiguous timeout).
7. **Two-phase approval:** a read-only preflight method produces `payload_hash`, approved warehouse, order ref, shipping mode and sanitized SKU+qty/blockers, without leaking recipient PII; separate execution method requires exact numeric ERP order ID, exact order reference, exact preflight hash, explicit typed confirmation `SUBMIT_SHIPOUT_ORDER_<ID>`, production flags all correctly set, fresh full preflight, separate Owner approval.
