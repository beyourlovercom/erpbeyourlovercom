# ERP1 全仓库物流回传统一规则

Owner 2026-11-27: 所有已接入发货/状态 API 的仓库，每五分钟回读物流单号和 OMS 处理状态；有有效 Tracking 或 API 明确终态即停止该单自动轮询。仓库间错峰：德国 00/05/...，纽约 02/07/...，MorePlus 04/09/...。不改变库存同步、官网同步频率，不恢复已停止合作的世迈自动发货，不为没有可信接口的仓库模拟调用。每次有界扫描最旧记录优先，防止重复并发、对方限流和头部饥饿。

- XLWMS NY/DE: 已确认的本仓订单，pending、审核通过、无 Tracking 才查询；状态 3/4（已出库/取消）终止后续轮询。先在该轮校验并回填有效单号，缺单号保留终态供人工核查。
- ShipOut MorePlus: 原有只读对账机制继续复用，签名 GET 状态及精确订单详情，单一且所有包裹同号的有效 USPS Tracking 可暂存；明确终态取消/中止停止，已出库最后一次核验真实单号及包裹，缺失时追加 TERMINAL_TRACKING_REVIEW 审计状态后停止。原始 API ACK 和之前 OMS 证据保持不变。
- 任何仓库不得自动重发/创建，不覆盖人工已有运单，不将标签生成等同于发货，不改变 Vita 官网同步门禁。
- ERP1 专用，ERP2 禁止修改。正式启用须在 CI、并行发布基线及真实调度器核验后执行。
