# ERP Sync Global Grid · 第二行列筛选（2026-11-11）

## 背景
- 当前 Production 同步订单总表已默认使用统一 AG Grid（PR #722、#724）。
- 生产只读盘点约 8,007 单，其中约 2,071 条发货、1,893 条 Woo 来源已填写 Tracking。
- 当前同步状态由 ERP 持久化凭证与 Woo 回读组合计算，原本仅对分页结果计算；严禁直接过滤当前页的 50 单并冒充全库筛选。

## 界面
- 复用现有 OmsGrid 浮动列筛选组件，表头第二行展示订单号、日期、来源、收件人、承运商、Tracking 筛选。
- 最右「同步进度」显示下拉选项：全部状态、未同步、同步失败、已同步、已通知。
- 所有条件保留在服务器搜索、排序、20/50/100 分页之间；保留 ?global_grid=0 旧表入口。
- 不更改操作权限、右侧固定列、账号布局保存、同步按钮及 Tracking 安全规则。

## 全库同步状态筛选
- 独立只读状态快照，有效期五分钟；从 ERP 全部订单判断非默认状态，优先扫描有 Shipment 或 ManualSync 凭证的候选订单。
- 若 Woo 连接可用，按原有 WooCommerceTrackingBatchInspector 批量只读核验，沿用 LogisticsTrackingListStatus 和 OrderSyncProgressProjector 的证据判定；没有凭证的订单保守归为未同步。
- 快照按真实 ERP 全部订单建立状态索引，在 MySQL/SQLite 端完成筛选后再分页，计数是筛选全库后的计数。
- 前端展示快照生成时间、总覆盖数；由于缓存，结果可能比 Woo 官网当前变化延后最多约五分钟。
- 远程回读失败或首次全库扫描超过 35 秒，则拒绝输出不完整筛选结果并返回友好错误。不将未经核验的订单冒充已同步。
- 无 Woo 写入、Customer Note、订单变更、数据库迁移、调度器、Queue 或生产环境开关变更。

## UAT / 发布门禁
- 美国 Mac mini 独立 UAT：http://127.0.0.1:18871/sync/orders，SQLite 合成数据，无 Woo 凭证。
- PHP 测试包括全库跨页数量、四态筛选、组合筛选、中文来源映射、Woo 回读故障阻断；Vue 测试包括列筛选参数、状态下拉和权限。
- 发布前仍需检查 GitHub CI、Owner 视觉验收，以及正式环境首轮状态核验的性能和 Woo API 读取频次。
- 若首轮真实全库扫描过慢，须改为独立受控的增量预计算模式，不能让正常订单页面长期阻塞。
- 本分支只供 Dev/UAT，不授权直接 Production 部署，保留原版回滚入口。
