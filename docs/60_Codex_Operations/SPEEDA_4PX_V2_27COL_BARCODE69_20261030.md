# 速达 / 4PX 2026-10-26 官方新版导出契约（R1–R4）

## 来源与范围
- 来源：Owner 上传 `速达--新模版1026（26款）(1).xls`（标准上传格式、国家对照表）。**原文件含真实收件人信息，不进入 GitHub。**
- XLS BIFF 只读检查确认上传格式 **A:AA 共 27 列**；原 A:X 24 列名称和排列未变化。
- Y（第 25 列）：商家产品识别码 → ERP 已核实的履约 SKU。
- Z（第 26 列）：制造商产品识别码 → Product OS `products.barcode_69`（文本，保留前导零）。
- AA（第 27 列）：国际标准商品编码 → **始终留空**，不允许自动填充 GTIN。
- 国家对照表继续保留；ERP 导出文件仍为 .xlsx，列结构符合新模板。

## 业务规则
- **仅速达 4PX** 改为 27 列；纬狮 Weship 仍单独使用原 24 列模板，旧导出/回传接口不变。
- **2026-10-30 Owner 微调：所有目的地的速达订单均尝试填写 Y=履约 SKU、Z=69码，有值填写、空缺留空；不再仅限欧洲。**
- Y 由订单行唯一且非空的履约 SKU 提供。Z 仅在 ERP Product OS 中唯一精确匹配该 SKU 且产品关联一致、条码格式有效时填写；缺失则留空。AA 在所有订单都留空。
- 1 个 SKU 多件或多条同 SKU 行：Y 使用唯一 SKU，Z 有 69码则填；原 Q 列继续填数量合计。
- 多个不同 SKU 的订单：由于官方 Y/Z 仅各有一个字段，Y/Z 留空，**不因这两列阻断订单**；不拼接/猜测/自动拆单。
- SKU / 69码空缺、产品关联冲突、产品表 SKU 未匹配：Y/Z 按已核实内容部分填写或留空，**不阻断导出**。原 A:X 必填字段校验仍必须执行。
- 原 A:X、国家对照、重量/品名/数量、IOSS、回传模板及审核流程保持不变。

## 代码实现
- `SpeedaOutboundExporter` 在原稳定基础模板上构造 Y:AA 3 列并复制行样式，避免改动稳定的旧字段。
- `SpeedaOutboundExporter::optionalIdentifiersForOrder` 仅核实单一履约 SKU 与产品条码；字段缺失时不改变 `blockers`，原 A:X 逐单必填校验保持。独立欧洲小包查询 API 的严格规则不受本次调整影响。
- `DomesticLogisticsController` 保持正确承运商标签与权限；纬狮导出仍为 24 列。
- UI 明确显示 4PX 27 列模板、Weship 24 列模板。

3. 美国等非欧洲订单能输出 SKU/69码；缺条码只留 Z 为空；缺 SKU 或多 SKU 时 Y/Z 为空，不阻断原已通过校验的订单。
4. 原 A:X、纬狮 24 列、国内物流和回传流程回归。
