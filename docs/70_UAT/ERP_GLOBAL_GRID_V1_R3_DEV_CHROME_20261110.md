# ERP Global Grid V1 · R0–R3 isolated Dev UAT · 2026-11-10

## Boundaries
- **Dev-only opt-in** `global_grid=1` with `GlobalGridPilot::enabled()` double gate: APP_ENV local/testing/development; all Production requests fail closed.
- Three representatives: Products standard list, Inventory products, Procurement orders.
- Unchanged default/legacy paths and product factory task tabs, purchasing mobile cards, existing DOM-linked business operations.
- Shared engine: the only `OmsGrid.vue` instance, wrapped by `GlobalGrid.vue`, lazily imported; cell actions generated by explicit caller permissions and URL whitelist.
- Independent per-module account preference namespaces. No migrations, no Production access, no real business order writes.
- Product list remains bounded by its existing server paginator; inventory page uses 20/50/100; procurement pilot alone replaces legacy unbounded `get()` with 20/50/100 server paging. No “全部” option for canary.

## Browser performance — measured, not invented
Single test-run observations on US Mac mini, authenticated Chrome, loopback Laravel. Same test rows, same browser, equivalent navigation. `visible` = page navigation until actual table and representative data appear; `idle` = all follow-up AJAX/asset requests settle. One measurement per page; these are **not statistical benchmarks or Production latency forecasts**.

| Page | Legacy visible | Global Grid visible | Legacy network idle | Global Grid network idle |
|---|---:|---:|---:|---:|
| Products | 143 ms | 181 ms | 651 ms | 1,191 ms |
| Inventory | 85 ms | 137 ms | 578 ms | 1,147 ms |
| Procurement | 96 ms | 171 ms | 619 ms | 1,186 ms |

Additional visible delay: +38 / +52 / +75 ms. Full network-idle extra ~0.5–0.6 sec from lazy initial module & per-account preference request; subsequent visits benefit from browser cache. The old route does not import the new Global Grid bundle. Do **not** describe this as a server resource comparison. Follow-up R4 performance can consider preference prefetch/cache if measurements on realistic data demand it.

## Bundle reduction
Original OMS Grid AllCommunityModule: 1,273,960 bytes JS; gzip ~342 KiB. Explicitly register only necessary AG Grid Community modules (no unused cell editors/infinite row model): ~1,087,302 bytes JS; gzip ~293 KiB, **~14.4% smaller transfer**. The existing OMS browser import/permissions tests pass with the same module set.
