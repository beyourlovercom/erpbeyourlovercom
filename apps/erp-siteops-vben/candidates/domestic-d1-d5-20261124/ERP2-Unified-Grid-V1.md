# ERP2 Unified Grid V1 — frozen 2026-11-24
Approved architecture: one engine, one shared Grid, reusable feature library, module field registries, page declarative data scope and capabilities. Each employee owns independent preferences for every page/queue/warehouse. Never share layouts by default. Preserve Laravel identity, permissions, query/write/export contracts. Account preference namespace is stable per page; use existing user_ui_preferences, no new database. Do not copy grid components per page or keep parallel legacy grids. New columns use stable IDs; new features default according to supported capabilities; preferences never grant permissions. Only logistics P0 is in scope now. Other modules follow this standard when migrated. Missing backend fields/capabilities must be explicitly audited and mapped; no fake sorting/filtering or silent unsupported writes.
